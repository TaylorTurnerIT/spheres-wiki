**Target**: see text.

**Disable Device DC**: 15 + the caster level or gizmo level of the object (if any).

You sabotage the target to disrupt those that use it.

If this sabotage is applied to a spellcasting focus, implement, or material component, whenever the sabotaged object is used as part of a spell, magical sphere effect or supernatural ability, it suffers from a 100% spell failure chance.
    If an effect fails due to this sabotage, the user produces a mishap (Will negates), dealing 2d6 points of damage to them. This mishap can be controlled using the control mishap Spellhacking sphere ability. 
    The sabotage can be removed as a standard action with a successful Spellcraft or Use Magic Device check opposed by your Disable Device result.

If this sabotage is applied to a technological device (such as a gizmo), whenever the device is used to activate an ability, it becomes deactivated and broken (ending any effects it is producing, if relevant), and the user suffers 2d6 points of damage (Reflex negates both the condition and damage). The damage type of this damage is usually fire or electricity, but depends on the nature of the device (up to GMs discretion).
    The sabotage can be removed as a standard action with a successful Craft (mechanical) or Disable Device check opposed by your Disable Device result.
