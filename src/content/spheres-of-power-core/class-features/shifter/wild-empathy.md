Improve attitude of an animal. Functions like Diplomacy check to improve attitude of a person.

- **Check:** 1d20 + shifter level + Cha modifier.
- **Range:** 30 feet. Requires shifter and animal to study each other.
- **Time:** Generally takes 1 minute.
- **Magical Beasts:** Can use on magical beasts with Int 1 or 2, but -4 penalty.
