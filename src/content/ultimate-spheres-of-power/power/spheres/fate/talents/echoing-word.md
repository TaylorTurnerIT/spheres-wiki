---
id: "echoing-word"
name: "Echoing Word"
tier: basic
tags: ["mass"]
---

When using a word, you may spend an additional spell point to affect an additional 1 target per 2 caster levels (minimum 1) at the same time. Each target must be within range and must be affected by the same word (thus, if using the Open/Close talent, you could only target objects with this ability). Once created, each word is considered a separate sphere effect.
