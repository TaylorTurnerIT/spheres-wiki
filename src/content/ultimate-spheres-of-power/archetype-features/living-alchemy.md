This ability functions as the druid's animal companion class feature (nature's bond), except that the Ooze Chemist must choose the symbiotic ooze companion (listed below). At 1st level an ooze companion doesn't gain the share spells class feature or the multi-attack class feature at 9th, but instead gains the symbiotic extracts class feature. This replaces the bombs class feature and all bomb-based discoveries.
