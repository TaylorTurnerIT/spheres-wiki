The conduit may use evoke dweomer with technological items as if they were magical items, treating technological items as having no school or sphere of magic. An exhausted technological item functions as if it has no charges.

When using this esoterica, the conduit creates a Technomancy Sphere sprite which can be augmented with the following talents: Concealed Sprite, Lingering Sprite, Sprite Sustenance.
If the item used is a technological item or a magic item with the Technomancy sphere in its construction requirements, they can augment the esoterica with the following options: any (program) talent, Rapid Transfer, Reactive Offload.
