**Prerequisites:** Artifice Sphere

When attempting a challenge as part of dynamic magic item creation, you may spend a use of skill leverage to attempt both tasks yourself.

If a challenge from dynamic magic item creation results in a failure, you may spend a use of skill leverage to change the result into a success, in which case the item gains an additional quirk.

If a challenge from dynamic magic item creation results in a critical failure, you may spend a use of skill leverage to reduce the result to a normal failure (in which case the item gains an additional quirk) or a success (in which case the item gains an additional flaw).
