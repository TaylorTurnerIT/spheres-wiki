## How to Read This Report

Each missing item includes:
- **Exact name** as it appears on the old wiki (with tags)
- **Old wiki heading level** — always `<h4>` for talents, `<h3>` for archetype/class option sections
- **TOC position** — which section it falls under (e.g., "under Athletics Talents, before Move Aside")
- **Source book** — `[3PP]` = third party, `[Apoc]` = Spheres Apocrypha, `[EO3]` = Expansions 3, etc.

### Old Wiki TOC Structure (Might)

All Might sphere pages on the old Wikidot wiki follow this structure:
```
<h1> Sphere Name </h1>
  <h2> Base Ability Description </h2>
  <h3> Sphere Talents </h3>           ← section header (NOT a talent)
    <h4> Talent Name </h4>            ← actual talent
    <h4> Talent Name [source] </h4>   ← talent with source tag
  <h3> Legendary Talents </h3>        ← section header
    <h4> Legendary Talent Name </h4>
  <h3> Archetypes </h3>               ← deferred to archetype pages
  <h3> Archetype Name (Class) </h3>
```

Every `<h3>` and `<h4>` gets a `#toc` anchor and appears in the Wikidot auto-generated TOC.

### How to Parse Old Wiki Source

Each talent in the cached old page can be found by its `id`:
- **`<h4 id="tocN"><span>Talent Name</span></h4>`** — talent heading
- Text follows until next `<h4>` or `<h3>`

Example extraction:
```bash
# Find Mobility talent in Athletics page
grep -A50 'id="toc27"' cache/old/spheresofpower_wikidot_com_athletics | sed 's/<[^>]*>//g'
```

### Categories on New Wiki

New Might wiki organizes talents under section labels in the TOC sidebar:
- `data-toc-section="overview"` — base abilities, packages
- `data-toc-section="athletics-talents"` (varies by sphere) — regular talents
- `data-toc-section="legendary-talents"` — legendary talents

Missing talents should be added to the appropriate talent section with correct tags: `Talent`, `Basic` (or `Legendary`, `Stance`, etc.), plus source tags and subtype tags like `(motion)`, `(demoralization)`, `(deflect)`.

## False Positive Patterns (Might-Specific)

### 1. Unicode Apostrophe Collisions (most common)
Old wiki uses standard apostrophes (`'`, ASCII 0x27). New wiki uses Unicode right single quotation marks (`'`, U+2019). All items with apostrophes in their names that appeared in both MISSING and EXTRA lists are false positives.

**Total affected**: ~30 items across all spheres. Every one verified present.

### 2. Unicode Ellipsis (Duelist)
Old wiki: `&#8230;And Stay Down!` (HTML entity for horizontal ellipsis)
New wiki: `...And Stay Down!` (three ASCII periods)
Content present (2 hits). False positive.

### 3. Case Differences (Trap)
Old wiki: `All Part Of The Plan` (title case prepositions)
New wiki: `All Part of the Plan` (lowercase prepositions)
Content present (2 hits). False positive.

### 4. Archetypes and Class Options (~200 items)
Every Might sphere page on the old wiki lists archetypes. These are not sphere-page content gaps — the new wiki handles archetypes on separate class pages. All "Archetypes", "X Sphere Class Options", and individual archetype names (Doctor, Harmacist, Beast Bender, Adamant Guardian, Vajrahasta, etc.) are DEFERRED.

### 5. Section Headers as Talents (~40 items)
Old wiki auto-generates TOC from ALL heading levels. Section headers like "Adrenaline Talents", "Boast Talents", "Bleed Talents", "Dart Talents", "Deflect Talents", "Disarm Talents", "Exertion Talents", "Handle Animal Talents", "Manhandle Talents", "Shout Talents", "Slam Talents", "Snare Talents", "Tactic Talents", "Zone Talents" are `<h3>` section organizers, not talents. New wiki organizes differently.

### 6. Base Abilities / Legacy Section Names
"Active Defense" (Shield), "Sweep" (Open Hand), "Deadly Shot" (Sniper), "Swift Hands" (Scoundrel), "Marked Target" (Scoundrel) — these are base sphere abilities or section overviews. They are present in the page body but may lack dedicated TOC sidebar entries.

## Parsing Old Wiki Source: Quick Reference

# Extract a specific talent from old cache
grep -A50 'id="toc27"' cache/old/spheresofpower_wikidot_com_athletics | sed 's/<[^>]*>//g'
